# Abbott Law College Management System - Local Setup Guide

Complete guide to run this project on your local computer.

---

## Prerequisites

### 1. Node.js (Required)
- **Version**: Node.js 20+ (LTS recommended)
- **Download**: https://nodejs.org/

Verify installation:
```bash
node --version   # Should show v20.x.x or higher
npm --version    # Should show 10.x.x or higher
```

### 2. PostgreSQL Database (Required)
Choose ONE of these options:

**Option A: Neon Database (Recommended - Free & Cloud)**
- Sign up at https://neon.tech/
- Create a new project
- Copy your connection string

**Option B: Local PostgreSQL**
- Install PostgreSQL from https://www.postgresql.org/download/
- Create a database: `CREATE DATABASE abbott_college;`

## Installation Steps

### Step 1: Download/Extract the Project
Extract the project files to your desired folder.

### Step 2: Install Dependencies
Open terminal/command prompt in the project folder:
```bash
npm install
```

### Step 3: Install cross-env (Windows Users REQUIRED)
Windows users MUST install cross-env:
```bash
npm install --save-dev cross-env
```

Then update `package.json` scripts section to:
```json
"scripts": {
  "dev:client": "vite dev --port 5000",
  "dev": "cross-env NODE_ENV=development tsx server/index.ts",
  "build": "tsx script/build.ts",
  "start": "cross-env NODE_ENV=production node dist/index.cjs",
  "check": "tsc",
  "db:push": "drizzle-kit push"
}
```

### Step 4: Create Environment File
Create a file named `.env` in the root folder (same folder as package.json):

```env

# Session Secret (Any random string for security)
```

**For Local PostgreSQL, use:**

## Running the Application

### Start Development Server

**Mac/Linux:**
```bash
npm run dev
```

**Windows (with cross-env installed):**
```bash
npm run dev
```

**Windows PowerShell (Alternative without cross-env):**
```powershell
$env:NODE_ENV="development"; npx tsx server/index.ts
```

### Access the Application
Open browser and go to: **http://localhost:5000**

## Windows-Specific Instructions

### Method 1: cross-env (Recommended)

1. Install cross-env:
```bash
npm install --save-dev cross-env
```

2. Update package.json scripts:
```json
{
  "scripts": {
    "dev": "cross-env NODE_ENV=development tsx server/index.ts",
    "start": "cross-env NODE_ENV=production node dist/index.cjs"
  }
}
```

3. Run normally:
```bash
npm run dev
```

### Method 2: Git Bash
Install Git for Windows, use Git Bash terminal - supports Unix commands.

### Method 3: PowerShell Direct
```powershell
$env:NODE_ENV="development"
$env:DATABASE_URL="your-database-url"
$env:SESSION_SECRET="your-secret"
npx tsx server/index.ts
```

## Troubleshooting

### "Cannot connect to database"
- Check DATABASE_URL is correct in .env
- For Neon: Ensure internet connection is active
- For local: Start PostgreSQL service

### "NODE_ENV is not recognized" (Windows)
- Install cross-env and update package.json scripts
- Or use PowerShell method above

### "relation does not exist"
Run database migration:
```bash
npm run db:push
```

### "Module not found"
```bash
rm -rf node_modules
npm install
```

### Port 5000 in use
Change PORT in .env to 3000 or another number.

### Login not working
Ensure SESSION_SECRET is set in .env file.
